# Antigravity 地区资格：查哪项、改哪项、怎么改

官方资料核对：2026-11-26。每次实际排障重新查看下列官方页面与当前账号，不固定支持国家名单或变更周期。此分支是官方更正指引，不是已实测成功的解锁方案。

## 诊断与最小变更

先核对App、浏览器、条款页右上角是否同一账号；只记录必要的账号后缀、错误原文、核验时间。询问实际居住国家（不需详细地址），不能用出口IP、界面语言或旧截图代替。

| 当前证据 | 应处理哪项 | 不应默认改什么 |
|---|---|---|
| Antigravity明确提示地区不可用，条款关联国家与实际居住国不符 | 请求更正Google账号关联地区 | 不默认改Play、付款、家庭组 |
| 条款国家正确，但实际所在国家不在支持名单 | 说明当前不可用；提供官方支持范围 | 不提供虚假居住证明、地址或保证换线路可用 |
| 条款国家受支持，仍然不能登录 | 核对本次账号、年龄/组织限制及最新错误；走对应官方支持 | 不把所有失败归因为地区，不反复提交更正 |
| Google Play购买页面明确提示Play国家不匹配 | 只进入Play国家流程 | 不将Play设置当Antigravity关联地区的替代值 |
| 购买/付款流程明确要求新国家付款资料 | 核对选中的付款资料；确有需要才新建对应国家资料 | 不关闭旧资料、取消订阅或重购 |
| 只有Gemini通用报错/code=9 | 返回日志及同账号网页对照 | 错误码本身不足以要求改地区 |

## A. Antigravity首先看Google账号关联地区

官方依据：[Antigravity FAQ](https://antigravity.google/docs/faq#what-is-google-antigravitys-geographical-availability) 明确要求检查条款页国家，错误时申请更正。页面也列出支持国家及年龄等条件。

1. 登录目标账号，打开[Google服务条款](https://policies.google.com/terms)，核对右上角账号和页面国家/地区版本。不要手动选择一个国家展示条款后，将该展示值当成账号已更正。
2. 对照上面FAQ的当前支持名单；只报实际查到的值，不笼统说“全部改美国”。
3. 如果账号关联地区不符合实际情况，打开[关联地区更正申请](https://policies.google.com/country-association-form)。它要求登录；本次公开抓取只能确认跳转到登录页，不能预设登录后表单字段。
4. 确认目标账号，按表单选择真实国家/地区，填写真实更正原因；只在页面要求时提供必要材料。可以协助把用户事实整理成说明，不编造搬家、长期居住或地址。
5. 用户检查内容后按页面提交。身份验证由用户完成；如出现工具规则要求确认的条款或权限，在当时处理。记录“已提交”，不写“已通过”，不承诺审批时长。
6. 收到结果后再用同一账号查看条款国家，重新登录Antigravity并真实发送测试。区分：申请通过、账号国家改变、App登录成功、模型回复成功，逐项验收。

若实际居住国不受支持且关联正确，说明无法通过合法的资料纠错解决；若关联正确且在支持名单内，转当前官方FAQ/应用反馈渠道继续处理，不让用户无依据反复改地区。

## B. 仅在Play国家确实是故障项时处理

入口：[Google Play](https://play.google.com/)；[电脑与Android官方步骤](https://support.google.com/googleplay/answer/7431675?hl=zh-Hans)。

电脑：头像 → 设置 → 国家和个人资料；Android：Play商店 → 头像 → 设置 → 常规 → 账号和设备偏好设置 → 国家和个人资料。按当前界面为准。

区分新增国家资料与切换已有资料：新增按官方要求满足所在地及当地支付方式；已有资料切换按页面操作，不能一律声称必须重新绑卡。入口缺失时查当前位置、变更间隔及家庭成员状态。官方本次写明至少90天变更间隔、部分情况额外限制，更新可能需48小时；执行前重新核对，不把该时限套用到条款关联地区申请。

家庭成员不能直接更改Play国家。先解释下节影响，让用户决定是否值得做；不要把退组或删除家庭列为默认修复步骤。旧余额、积分、内容和订阅可能受影响，具体查官方页，不自动取消或重购。

## C. 付款国家与地址

入口：[Google付款中心](https://payments.google.com/) → 设置 → 选定付款资料 → 国家/地区。
[个人付款资料说明](https://support.google.com/faqs/answer/7644003)；[国家及地址操作说明](https://support.google.com/faqs/answer/7644076)。

现有付款资料的国家不能直接改成另一个国家。确需在新居住国家购买服务时，按页面：国家旁编辑 → 创建新资料 → 选择真实国家 → 填真实地址 → 检查提交。更改同一国家内的地址不等于更改账号关联地区。已有订阅不会因新建资料自动迁移；不要删除旧付款资料或承诺新建后Antigravity就能登录。付款方式、证件与敏感地址不写入排障记录，支付动作按当次工具规则由用户处理。

## D. 家庭组关联影响

[家庭组官方说明](https://support.google.com/families/answer/6317858?hl=zh-Hans)；[家庭管理入口](https://g.co/YourFamily)。家庭成员需与管理员居住在同一国家。退组可能失去共享存储、AI权益；换组存在限制，规则应当次核对。

只申请纠正条款关联地区，不等同主动退组。没有证据时既不保证“绝不影响家庭组”，也不声称“必然被踢”。若Play变更要求离组，先明确用户是普通成员还是管理员，说明共享权益损失；不自动退出/删除家庭组。用户明确选择离组后，才给对应官方页面的操作步骤或在授权范围内协助。

## 每次必须交付给用户的答案

不能只说“地区问题，自己去改”，应给出：
- **查到什么**：哪个账号、哪一项国家、哪条错误；未知项目标明未核实。
- **这次改哪项**：具体字段与证据；已经正确的项目明确不用动。
- **在哪里改**：上述直接可点击的官方入口。
- **怎样改**：针对当前设备和页面的短步骤，真实材料要求。
- **改动影响与验收**：涉及Play/付款/家庭的实际影响；提交后等什么结果、回哪里核验、如何测App。

示例（仅当事实吻合）：你的Antigravity报地区不可用，条款页显示A国，而你实际居住在受支持的B国。本次先申请更正账号关联地区：打开[更正入口](https://policies.google.com/country-association-form)，确认账号，按页面选B国并如实说明原因。Play和付款资料先不动，也不退出家庭组。审批结果出来后重新核对条款页，再登录App测一条真实回复；申请获批不等于已保证登录成功。
